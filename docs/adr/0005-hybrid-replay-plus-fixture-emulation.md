# Эмуляция СМВУ: replay реальных данных + библиотека fixture-сценариев

Контекст: организаторы одновременно требуют, чтобы эмулируемый поток выглядел правдоподобно (не случайный шум), и нужен управляемый нарратив для демонстрации конкретных сценариев (например, «вот начинается пожар») перед экспертами.

Решение: near-real-time поток СМВУ строится как хронологический replay реальных исторических данных (`журнал_событий_пример.csv` и операционное окно из архива) как «фоновый шум», поверх которого можно включать библиотеку из ~12–20 скриптованных fixture-сценариев (по аналогии с §16.4 фронтенд-ТЗ) для управляемой демонстрации. ОДС/реестр оборудования/система заявок эмулируются полностью синтетически (для них реальных данных нет вообще).

Почему: закрывает оба требования организаторов одновременно (правдоподобность фона + управляемый демо-нарратив), и даёт фронтенд-команде тот же набор fixture-сценариев для их mock-adapter — снижает рассинхрон между командами при параллельной разработке.
